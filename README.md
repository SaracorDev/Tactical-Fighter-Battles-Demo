# Tactical Fighter Battles — Demo

Turn-based tactical hex wargame for Windows. Jet fighters and attack aircraft fight over a hex map with NATO-style counters. This is a board game that runs on a computer, not a flight simulator.

This repository **hosts the Windows demo download**. Source code is not included and is not licensed.

## Download

**[TacticalFighterBattles-DEMO-1.2.0-windows.zip](https://github.com/SaracorDev/Tactical-Fighter-Battles-Demo/releases/latest)**

Unzip anywhere and double-click `TacticalFighterBattles.exe`. Godot does not need to be installed.

- 64-bit Windows 10 or 11
- A GPU with Vulkan (typical PCs from about 2016 onward)
- If the window is black or the game exits immediately, the GPU may not support Vulkan
- Windows SmartScreen may warn because the build is unsigned: **More info** → **Run anyway**

## What's in the demo

- **DEMO - 1.2.0**
- United States and USSR only
- Eras 1–3 (1945–1990)
- Dogfight and base destruction, plus three tutorials
- No pilots, no campaigns, no extra nation packs

You command the attacker. Defending jets intercept on their own. Gold hexes are the next step; grey hexes are where you can finish a fly.
